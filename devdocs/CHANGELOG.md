### 📖 阅读

- **修复**：书籍原排版下用「卷曲」翻页时，刚打开书翻不动页（要切一次翻页模式才恢复）。原因是预加载视图的章节加载被中断后仍被记为"已加载"，后续对同一目标只在空白文档上请求准备下一页，等待"下一页就绪"的卷曲翻页就永远排队；现在加载被打断会清掉该视图的章节记录并自动重新加载，另外给"目标页迟迟不就绪"加了兜底：预加载长时间没有进展时直接翻页，避免点击石沉大海
- **修复**：书籍原排版进入时定位比退出位置靠前（用户反馈"少两页"）。原因是恢复用的精确文字锚点在文档还没分页时就被应用、被夹到第 0 页后丢弃；保存的锚点在无预加载页的翻页提交时会沿用上一页；章节分数按"页尾"存档而 WebView 按"页首"反解；章末最后一页还会落到下一章。现在锚点排到分页完成后再应用、位置移动且没有新锚点时不沿用旧锚点、分数语义与自研引擎一致、章末停在原章页尾
- **修复**：选「原排版」退出再进入时，主题面板高亮的不是「原排版」（实际生效却是）。现在书籍信息到位后会按当前排版模式的活动套装配额回写，显示与生效一致
- **修复**：原排版跟随系统深色/阅读器夜间模式注入夜间主题，浅色书页被反色成白字看不清。现在「原排版」固定使用原书配色、不响应深浅模式；显式切到夜间等套装仍按该套装渲染
- **新增**：书籍原排版新增内置主题套装「原排版」，并作为书籍原排版的默认套装：阅读器完全不参与配色，原书自己的底色、背景图与文字颜色照原样渲染（不再被阅读器底色替换、也不再被自动对比色改写）；该套装的背景与文字颜色不可更改，想覆盖配色可切换到日间/夜间等其他套装。阅读器排版与书籍原排版各自记住自己的活动套装，互不影响；墨水屏模式维持原有行为
- **修复**：阅读器排版下插图被强行画成正方形、横向插图被纵向拉伸的问题；现在按图片原始宽高比绘制，只有脚注小图标保持正方形槽位
- **修复**：阅读器排版下 SVG 图片只显示一个写着「SVG」的占位框；现在用矢量光栅化真正画出图（`<svg><image href="位图">` 直接取原图），失败才回落占位框
- **修复**：阅读器排版丢失原书装饰的问题：出版社用 CSS `background-image` 做的页面底图与装饰会还原成装饰图插在对应块前，并用发布方的 `width`（如 `12%`）排版装饰小图，不再一律拉满正文列宽；跟随「保留原书背景」开关，墨水屏模式下不注入
- **修复**：书籍原排版里「整页只有图片」的页面（封面、卷首图、插图页、固定版式整页图）被页边距缩进去一圈；现在这些页面满屏显示并忽略页边距，连续滚动下按满宽 + 自然高度显示，不再占满一屏留出大片空白
- **修复**：书籍原排版里发布方显式声明铺满宽度（`width="100%"` 或 CSS `width:100%`）的块级图片被页边距挡住；现在这类图片左右贴边，章首第一张连顶部页边距一起取消
- **新增**：书籍原排版新增「整页图裁切填满」开关（默认关闭）：开启后整页图片按屏幕比例裁切铺满，关闭时等比缩放到整页可见
- **修复**：书籍原排版里固定版式页面的图片在容器比例与图片不一致时被非等比拉伸；现在图片统一兜底 `object-fit: contain`，不改出版方给的宽高
- **优化**：书籍原排版丢失图片时，压缩包里缺资源与 WebView 子资源加载失败都会记日志（每条资源一次，最多 20 条），便于区分「书本身缺图」和「没画出来」
- **修复**：书籍原排版模式下，自定义阅读背景（纯色与图片）不生效。现在以用户背景为底层，原书自带图片/渐变背景的页面仍保留原书背景，其余页面显示用户设置的背景；「保留原书背景」关闭时所有页面统一使用用户背景
- **新增**：书籍原排版与阅读器排版各存一套高级设置（字号、字体、对齐、边距、背景与文字颜色等），互不影响；书内「高级设置」和「设置 → 阅读设置」都能切换正在编辑的排版模式
- **优化**：阅读器排版下全角标点挤压为半字宽（句读、引号、括号等），标点不再和汉字一样宽；行末标点按墨迹对齐，行尾右边缘更整齐
- **优化**：阅读页角落信息区的章节信息改为单行显示，标题过长时按宽度用省略号截断，信息区不再被撑成两行
- **修复**：TXT 章首大标题在「翻一页再翻回来」后挤成一团（正文正常，点一下屏幕又恢复）。原因是可见文字层在翻页槽位轮转、选择层排版还没就绪时，会退回到自己那份排版，而它的 `TextPaint.density` 是默认值 `1.0`：dip 标记的标题字号被量成 `1/屏幕密度`、字形却仍按屏幕密度绘制，大标题就叠成一团；现在退回到的那份排版也按屏幕密度度量 dip span，并与选择层使用同一条断行策略
- **修复**：上下滚动模式下，部分行最后一个字/标点被正文列右边缘裁掉半截。相邻章节预加载把「阅读器自绘」的挤压 span 交给了原生 TextView，排版只给标点半个字宽、框架却按整字宽落笔，行尾溢出被裁；现在滚动模式统一使用框架绘制变体，并保证挤压槽位不窄于字形墨迹（自定义字体的比例标点同样不会再越界）
- **修复**：EPUB/MOBI 阅读器排版下章节标题也会被首行缩进的问题；现在标题（h1–h6 及与章节标题同名的首段）不参与首行缩进
- **修复**：书籍原排版下自定义背景只在翻页动画期间可见、翻完页又恢复书籍白色的问题；自定义背景下由文档层直接铺出底色，并压制覆盖整页的纯色纸张背景
- **修复**：仿真卷曲翻页松手后收尾动画"一闪而过"、以及纸张卷到一半突然消失。原先收尾时长按整段几何行程分摊，而 NEXT 的行程里有约九成在屏幕外，可见的翻页只占最前面几帧；现在可见扫过段按松手速度播放（配置时长的 0.3–0.9 倍，甩手也有下限），终点用绘制同款判据（正文是否已经全部让开）按手势模式二分算出来（竖直拖、斜着拖、上下角起手各不相同），剩余的纸背再由 140–240ms 的尾段滑出屏幕

### 🔈 听书

- **修复**：连续滚动（上下滚动）模式下，无论滚动到章节哪里点「听书」，都会从本章第一句开始朗读；现在按当前滚动位置对应的字符偏移开始，并对齐到完整句子
- **优化**：听书启动后，手动翻页或滚动不再改变朗读进度，阅读页也不再被朗读位置自动拉回；朗读自身读完一页时仍会自动翻页继续
- **新增**：听书进行中双击正文任意句子，朗读即从该句开始（暂停状态下双击会直接继续朗读），双击位置所在页不移动，之后朗读翻页重新跟随阅读页
- **新增**：支持耳机线控与蓝牙耳机按键控制听书：播放/暂停、上一句、下一句、停止都能用耳机按键操作（MediaSession 会话回调、媒体按键广播接收器、前台窗口按键兜底三条投递路径）
- **优化**：听书面板把速度、定时改为图标（定时生效时仍显示倒计时），播放/上一句/下一句改为实心圆润图标
- **修复**：系统媒体播放器（锁屏、下拉媒体控件）不显示书籍封面；现在按当前书籍写入会话元数据，展示书名、作者与封面（无封面时用应用图标占位），通知同步显示封面大图
- **修复**：部分机型耳机按键无法暂停/播放听书。原因是听书播放期间无人持有音频焦点，系统把媒体按键路由给上次播放音频的应用；现在系统 TTS 播放时主动持有音频焦点，被电话/导航抢占会自动暂停、短暂中断结束后自动继续
- **优化**：悬浮窗字幕长句不再用省略号截断，改为从句子开头左右滚动到句尾一次（短句不动、新句子重新从开头滚）；开启「减少动态效果」时保持省略号显示
- **修复**：悬浮窗设置页每次进入时预览窗都停在默认位置（首次组合时读到的还是默认参数，保存的位置参数本身是对的）；现在预览始终使用最新参数
- **修复**：应用退到后台或阅读器已关闭时，读完一页会长时间停住（朗读在等阅读页确认翻页，而确认不会再来）；现在 1.2 秒内没有确认就继续朗读
- **修复**：悬浮窗字幕偶发闪烁（逐句朗读时字幕会被清空成「正在朗读」、每次状态刷新都重复 setText、自动字号在 12–18sp 间跳动）；现在上一句保留到新句开始、只在文本变化时更新、字号固定 16sp

### 📚 书库

- **优化**：长按书籍封面/分类文件夹弹出菜单的入场动效不再发粘。原先两个玻璃面板要等 `80ms` / `190ms` 才起步、再走 `stiffness 145` 的慢弹簧，完全成形要 700ms 以上；现在信息面板立刻进入、操作面板只晚 60ms，弹簧提到 `420` / `380`，约 130ms / 220ms 就基本成形，封面放大与遮罩同步加快，退场也从 400ms 收到 260ms。宫格、列表与分类页共用同一套参数（`ui/bookshelf/ContextMenuMotion.kt`）
- **新增**：「分类与标签」页的「自定义分类」支持折叠子文件夹：有子文件夹的分类左侧显示折叠按钮，点按即可折叠或展开整棵子树，叶子分类保留同宽占位让图标对齐；折叠状态在屏幕旋转重建后保留，长按菜单与点进分类的行为不变
- **新增**：独立 Cover Flow 书架，支持连续三维封面、直接拖拽与可打断弹簧、环境光和模糊倒影；阅读进度显示在书名后，长按保留当前封面并显示紧凑操作栏。文件夹通过顶栏返回上一级与横向导航行浏览，批量编辑临时进入列表。
- **优化**：切换到 Cover Flow 时展示随深浅主题变化的全屏幕布与流光衬线标题、Beta 标记，随后按钮和封面依次入场；阅读往返使用独立连续转场并按书籍 ID 恢复焦点。
- **修复**：Cover Flow 玻璃背景循环采样引起的 RenderThread 闪退、文件夹按钮采样白块、透视封面误命中及返回时系统栏变化导致的封面跳动；修正书籍加载后焦点派生状态未更新，滑到末尾只有书名而封面消失的问题。
- **新增**：导入弹窗第三项「更新书籍文件夹内容」改为「选择文件夹书籍」，在新 Activity 中以文件管理器方式逐层浏览授权文件夹（走系统转场动画）：每一层先列子文件夹再列书籍，点文件夹进入下一层、左上角或系统返回键回到上一层，标题下显示当前路径；进出文件夹复用书库页的过渡（旧层淡出上移、新层从下方淡入上移，返回时反向，减弱动态与电子墨水退化为短淡变/直切）；默认一行一本的列表，可切换成 2/3 列宫格（切换带缩小淡出/放大淡入过渡）。页面只展示上次扫描记住的内容，进入不再全量扫描；右上角可手动刷新，刷新时原地更新列表并提示「新发现 XX 本书籍」，已导入的文件带「已导入」标记
- **新增**：从文件管理器「打开方式」或系统分享导入书籍时，若已授权过书籍文件夹，会先询问「复制到应用内文件夹」还是「移动到授权文件夹内」（多个授权文件夹时可选择目标文件夹）；未授权文件夹时保持原有的直接复制行为
- **优化**：书籍文件夹内容的扫描结果会按授权文件夹记住（设备本地缓存），授权新文件夹、书架「刷新授权文件夹」或页面内刷新都会同步更新这份记录

### 🏠 首页

- **新增**：首页滑到最顶后继续下拉，上方留白会随下拉距离淡入「松手以继续阅读最近书籍」；松手时内容下移达到阈值（96dp，约手指 240dp）才打开继续阅读卡片当前那本书，未到阈值或原路推回只回弹、不打开。下拉阻尼与原有顶部回弹完全一致，空书库时该手势无任何效果

## v1.0.01.124 (2026-07-06) — 首个正式版本

### 📖 阅读引擎

- **自研 Canvas 渲染引擎**：StaticLayout 直接绘制到 Bitmap，3 槽位 PageSurfaceView 轮换，替代早期 WebView/TextView 方案
- **EPUB 解析器**：自实现 ZIP 解压 + HTML 解析，图片转为 Base64 内嵌到 HTML
- **PDF 解析器**：Android PdfRenderer 按需渲染 + LRU 缓存（最多 3 页）+ JPEG 压缩
- **TXT 解析器**：纯文本智能分章，包装为 HTML 布局
- **视差翻页动画**：SlidePageAnim 双层视差（覆盖层 100% 速度 + 主体层 25% 速度），Cubic Bezier 缓动，边缘阴影渐变，3 槽轮换实现无缝跨章
- **章节切换异步化**：修复主线程阻塞导致的白屏和卡顿问题
- **分页精确修复**：StaticLayout 与 TextView breakStrategy 对齐（HIGH_QUALITY）、共享 TextPaint 消除字体度量差异、includeFontPadding 处理
- **圆角裁剪**：Canvas clipPath 软件渲染兼容（setLayerType LAYER_TYPE_SOFTWARE）

### ✨ 文字选择与标注

- **原生文字选择**：setTextIsSelectable(true) + ActionMode 拦截，兼容 MIUI/MagicOS
- **自定义 Compose 选择菜单**：6 色高亮调色板 + 添加笔记 + 全文搜索 + 复制 + 移除高亮
- **SpanWatcher 拖拽检测**：300ms 防抖，拖动选择手柄自动重新弹出菜单
- **选择手柄 Compose 覆盖层**：从 Bitmap 渲染迁移到独立 Compose 层，消除坐标反馈环抖动
- **分层渲染**：文本层 + 标注层分离，拖动选择时只重绘标注层，大幅提升流畅度
- **BreakIterator 选词**：智能词语边界检测，精准选中中文词语
- **高亮持久化**：保存后重新渲染不丢失，点击已有高亮可修改颜色或删除

### 📚 书架与书库

- **书籍导入**：系统文件选择器，EPUB/TXT/PDF 过滤，自动提取封面和元数据
- **书籍展示**：Coil 封面加载 + 缓存，网格/列表布局
- **长按上下文菜单**：玻璃拟态遮罩 + 封面缩放动画 + 交错菜单项弹出
- **自定义封面**：从相册选取图片替换默认封面
- **编辑书籍信息**：书名、作者编辑（EditInputDialog 卡片风格组件）
- **收藏/取消收藏**：首页三点菜单快速操作
- **删除动画**：缩小 + 淡出动画

### 📊 阅读统计

- **今日阅读**：今日阅读时长 + 本周趋势柱状图
- **阅读目标**：每日时长目标设定，完成百分比显示

- **数据驱动圆圈**：首页每周打卡圆圈（完成/未完成状态）

### 🐛 关键修复

- **白屏问题**：11 项修复（包括 WebView 加载时序、章节切换竞态、字体指标对齐等）
- **文字溢出与内容断裂**：breakStrategy 不匹配 + TextPaint 字体度量差异 → 统一 StaticLayout 参数与共享 TextPaint
- **字体大小与分页联动**：修改字号后重新分页失败 → 强制重建 Layout
- **MIUI/MagicOS 兼容性**：ActionMode 隐藏（mode.hide(Long.MAX_VALUE)）、Spannable 死对象异常
- **章节切换卡顿**：runBlocking 主线程阻塞 → 异步化
- **笔记跳转定位**：跳转到笔记所在章节后页码不准确 → 修正 pageIndex 计算
- **阅读时长累积**：upsert 逻辑错误导致重复计数 → 修复插入/更新判断
- **R 角渲染**：GPU 忽略非矩形 clipPath → 软件渲染兼容处理
- **EPUB 链接文字消失**：CSS 伪类渲染问题 → ImageSpan 解析修正
