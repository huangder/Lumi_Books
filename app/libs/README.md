# Vendored Fluent icon subset

`fluentui-system-icons-used.jar` contains only the Regular and Filled vector
classes referenced by `AppIcons.kt`. It was extracted from
`io.github.niyajali:fluentui-system-icons-android:1.0.1` to avoid packaging the
entire icon catalog in debug builds.

`app/src/main/assets/licenses/fluentui-system-icons-mit.txt`.
