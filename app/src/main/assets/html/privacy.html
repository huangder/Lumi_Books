隐私政策

生效日期：2026年6月29日 · 最近更新：2026年8月30日

一、引言

Lumi（以下简称“本应用”）是一款开源、本地优先的电子书阅读器。我们深知隐私对您的重要性，本隐私政策说明本应用如何处理数据，以及哪些可选功能会把数据发送到您选择或确认的网络服务。

核心原则：阅读、书架、进度、笔记和大多数设置默认保存在本机。只有在您主动配置或启用 WebDAV 同步、MinerU 云端解析、第三方 TTS 合成等网络功能时，相应的书籍文件、阅读数据或朗读文本才会发送到对应服务。

开源透明：Lumi 原创代码以 GNU GPLv3 许可证发布，第三方组件遵循各自许可证，完整源代码公开可审查。

3.2 会发生网络传输的场景

  • 更新、公告、条款/政策版本检查：应用可能访问项目发布页或文档地址，并在您选择仿宋字体时从 GitHub Raw 或 jsDelivr 按需下载字体文件。
  • WebDAV 同步：当您配置并手动或自动同步时，应用会连接您填写的 WebDAV 服务器，上传/下载书籍文件、书籍清单（如文件名、哈希、大小、修改时间）以及阅读进度、书签、笔记和笔记对应的选中文本。
  • MinerU 云端解析：当您主动选择云端解析 PDF 时，所选 PDF、随机化文件名、网络 IP、解析参数、任务标识以及精准解析所需的个人 Token 会发送至 MinerU/OpenDataLab 相关服务，并下载解析结果。
  • 第三方 TTS：当您选择 OpenAI TTS、Xiaomi MiMo 或自定义兼容服务时，当前朗读文本段、模型/音色、风格提示和必要鉴权信息会发送至您配置的第三方服务，服务端如何处理数据取决于该服务的条款和政策。若您开启 HTTP 连接，API Key 和朗读文本可能未经加密传输并被窃听。
  • 封面搜索：当您进入网络封面搜索或提交搜索时，当前书名和搜索关键词会通过 WebView 发送至您选择的 Bing、百度或 Google 等搜索服务；这些服务也可能记录 IP、请求时间和浏览器网络信息。
  • 赞助页贡献者：当您打开赞助/贡献者页面，应用会请求 GitHub contributors API 并加载 GitHub 头像。GitHub 及其 CDN 会按自身政策接收网络请求元数据。
  • 外部链接：当您主动点击 GitHub、反馈、下载、第三方协议等链接时，会跳转到对应网站。

3.3 本应用不处理的数据

  • 不收集您的姓名、手机号、通讯录、精确位置等个人身份信息。
  • 不收集 IMEI、Android ID、MAC 地址等设备标识用于追踪。
  • 不集成第三方分析、广告、用户画像、第三方推送或崩溃上报 SDK。
  • 不提供 Lumi 账号系统或开发者运营的云端书库；WebDAV 是您自选服务器，数据由您自行控制。
  • 除上述由您主动配置、启用、进入或点击的网络功能外，不主动上传您的书籍和阅读内容。

四、数据存储与安全

  • 阅读数据库和设置存储在应用私有沙盒中，受 Android 应用隔离机制保护。
  • MinerU Token、WebDAV 密码、第三方 TTS API Key 使用 Android Keystore 加密保存，并已从系统备份/设备迁移规则中排除。
  • EPUB 阅读 WebView 会阻止外部网络资源加载，出版方 CSS 仅用于本地排版展示。
  • 临时上传、下载和解析缓存会在任务结束或缓存清理时删除；第三方 TTS 音频缓存可自动淘汰。
  • 您可以在应用内清除阅读历史、书签、缓存和相关配置；卸载应用会删除应用私有数据，但不会自动删除您设备上自行管理的原始电子书文件。

五、第三方服务与用户自选服务

本应用不集成分析、广告、第三方推送或崩溃报告服务。以下网络能力均为可选或由用户触发：

  • OpenDataLab / MinerU：用于云端 PDF 解析，独立于 Lumi 运营，使用前请阅读其服务协议和个人信息保护政策。
  • WebDAV 服务商或自建服务器：用于同步书籍和阅读数据。服务器地址、可用性、安全性、数据保存和删除由您选择的服务方或自建环境决定。
  • 第三方 TTS 服务：包括 OpenAI TTS、Xiaomi MiMo 或您配置的兼容接口。朗读文本、风格提示、API Key 使用和费用规则受对应服务条款约束。
  • GitHub 及其 CDN：用于更新、贡献者列表、头像和远程字体下载。GitHub 及 CDN 的网络日志、保存和删除规则由其自身政策决定。
  • Bing、百度、Google 等搜索服务：仅在您主动使用网络封面搜索时接收书名或搜索关键词，具体处理由对应服务政策决定。

如不希望书籍或文本离开设备，请不要启用 WebDAV 同步、MinerU 云端解析、第三方 TTS 或网络封面搜索，并使用本地阅读、本地解析和系统 TTS。

六、儿童隐私

本应用不针对 13 岁以下儿童，不会故意收集儿童个人信息。监护人如发现儿童可能通过可选第三方服务提交了个人信息，请联系我们并同时联系相应服务方。

七、隐私政策的变更

我们可能因功能、法律法规或第三方服务变化更新本政策。更新后将在应用内或网页公布，并更新“最近更新”日期；重大变化会通过应用内版本提示要求您重新阅读并确认。
