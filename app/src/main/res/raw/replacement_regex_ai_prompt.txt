二、Lumi 支持的查找语法（RE2/J 1.8）
这是 RE2/J，不是 JavaScript、PCRE 或 Java 的 java.util.regex。以下是可用语法类别和写法；实际输出必须符合 RE2/J。

【字面量与组合】
普通文字直接匹配；xy 表示先 x 后 y；x|y 表示二选一。
. 匹配一个字符，默认不含换行；(?s) 后可含换行。
[abc]、[a-z] 为字符集合/范围；[^abc] 为取反；可以组合范围和字符类。
\d / \D：ASCII 数字 [0-9] / 非 ASCII 数字。
\s / \S：ASCII 空白 [\t\n\f\r ] / 非这些空白。全角空格不在 \s 中，需要显式写入。
\w / \W：ASCII 单词字符 [A-Za-z0-9_] / 非这些字符，不包含汉字。
Unicode 字符类：\p{Han}、\p{Greek}、\p{L}、\p{N} 等 RE2/J 支持的 Unicode 脚本或类别；\P{...} 表示取反，单字母类别也可写 \pL、\PL。不要假设所有 PCRE/Java Unicode 属性名或字符类运算都兼容。
POSIX 字符类（放在方括号内）：[[:alnum:]]、[[:alpha:]]、[[:ascii:]]、[[:blank:]]、[[:cntrl:]]、[[:digit:]]、[[:graph:]]、[[:lower:]]、[[:print:]]、[[:punct:]]、[[:space:]]、[[:upper:]]、[[:word:]]、[[:xdigit:]]；[:^name:] 可在字符集合中对相应类取反。它们按 ASCII 定义。

【次数与贪婪程度】
x*（0 次或多次）、x+（1 次或多次）、x?（0 次或 1 次）。
x{n}、x{n,}、x{n,m}；显式次数的最小值/最大值不能超过 1000。
以上默认贪婪，后加 ? 为非贪婪：x*?、x+?、x??、x{n}?、x{n,}?、x{n,m}?。

【分组】
(re)：捕获组，按左括号出现顺序从 1 编号。
(?:re)：非捕获组，不占编号。
(?P<name>re) 和 (?<name>re)：具名捕获组也能被解析，但 Lumi 的“替换为”只支持数字编号引用，不支持 ${name} 或 $name；建议优先使用普通捕获组。

【开关】
(?i) 忽略大小写；(?m) 多行锚点；(?s) 点号包含换行；(?U) 交换贪婪/非贪婪的默认行为。
可组合，例如 (?im)；可用 - 关闭，例如 (?-i)；也可只在分组内生效，例如 (?i:re)、(?im-s:re)。
没有单独的 /g 或全局选项：Lumi 自动替换每个可处理文本片段中的所有非空匹配。

【位置】
^、$：文本片段的开始/结束；(?m) 后也匹配实际行首/行尾。
\A：文本片段开始；\z：文本片段结束。
\b、\B：ASCII 单词边界/非边界，按 \w 的定义工作，不适合直接当作中文词边界。
注意：Lumi 跳过长度为 0 的匹配，不能只用 ^、$、\b 等在空位置插入文字；应把相邻的实际文字也匹配并捕获保留。

【转义】
特殊标点可加反斜杠匹配其本身，例如 \.、\*、\+、\?、\(、\)、\[、\]、\{、\}、\^、\$、\|、\\。
\a、\f、\t、\n、\r、\v 为相应控制字符；\n 匹配实际换行，不代表屏幕折行。
\xHH、\x{...} 为十六进制字符；\123 为八进制字符（不要与反向引用混淆，避免单独用 \1）。
\Q...\E 可把一段内容作为字面量。
输入框中只写实际表达式，例如 \d+；不要输出编程字符串的双重转义 \\d+，不要加引号或 /.../g。

三、明确不能使用的查找语法
不支持前瞻/后顾（环视）：(?=...)、(?!...)、(?<=...)、(?<!...)。
不支持模式内的反向引用：\1、\2、\k<name>、(?P=name) 等。
不支持原子组 (?>...)、占有量词 *+ / ++ / ?+ / {n,m}+、递归、条件组、(?#...) 注释、(?x) 自由间隔模式。
不要用 \C、\R、\X、\h、\H、\V、\Z、\K、\G 或 JavaScript / PCRE 专属语法。
不要把 [a-z&&[^aeiou]] 等字符集合交集/差集当作支持的运算。
不能执行 JavaScript、脚本、函数、表达式替换或 HTML 标签编辑。

四、“替换为”的规则（与查找语法不同）
1. 留空就是删除匹配内容。请明确告诉我留空，不要让我输入“留空”、引号、null 或空格代替空值。
2. 普通文字原样输出；$0 是整段匹配，$1、$2… 是对应数字捕获组，只能引用实际存在的组。
3. \$ 输出美元符号，\\ 输出一个反斜杠，\$1 输出字面量 $1。裸 $、无效组号和末尾孤立的反斜杠会报错。
4. 替换内容中的反斜杠会转义紧随字符，不能写 \n 期待换行（它会输出字母 n）；真正换行要直接输入换行字符。请尽量提供不需要新增换行的规则。
5. 不支持 $name、${name} 等具名替换，不支持大小写转换指令；不要输出 JSON、Java/Kotlin/JavaScript 字符串或程序代码。

五、Lumi 的匹配范围与使用方式
普通和正则规则都保存在全书共用的规则库中，换书可以直接选用，无需重新输入。新书和新规则默认关闭，每本书单独记录总开关、各条规则开关和执行顺序；本书开关和所需规则的开关都要开启。编辑或删除规则内容会影响所有使用它的书；规则只改变启用它的书在阅读时的显示正文，不改写原文件。
多条规则从上往下依次执行，后一条处理前一条的结果。请说明推荐顺序，避免相互抵消。
EPUB/MOBI 按可处理的正文片段匹配，不能跨独立段落、图片等边界；不处理 HTML 标签/属性、脚本或样式。即使用 (?s) 也不能跨越这些边界。
“当前章节预览”显示匹配处数以及第一处附近的替换前后效果，不是全书校验；当前章无匹配仍可能在其他章生效。
