用户协议

一、协议的接受

欢迎使用 Lumi（以下简称“本应用”）。下载、安装、打开或使用本应用，即表示您已阅读、理解并同意受本用户协议约束；如不同意，请停止使用本应用。

二、应用说明

2.1 应用功能

Lumi 是一款开源、本地优先的电子书阅读器，主要功能包括：

  • 阅读 EPUB、TXT、PDF 格式电子书，管理本地书架、阅读进度、书签、笔记和阅读统计。
  • 通过系统文件选择器导入文件或授权文件夹，以便直接读取您指定位置的书籍。
  • 在应用内编辑 TXT，并在您确认保存时写回您授权的文件。
  • 提供系统 TTS 听书；也可由您主动配置 OpenAI TTS、Xiaomi MiMo 或自定义兼容第三方 TTS 服务。
  • 在您主动启用后，通过 MinerU/OpenDataLab 云端服务解析 PDF。
  • 在您主动配置后，通过 WebDAV 同步书籍、阅读进度、书签和笔记。
  • 在您主动配置并启用或手动触发后，通过 Xiaomi MiMo、DeepSeek、OpenAI 或自定义兼容服务翻译选中的文本。
  • 在“设置 → 服务 → 本地词典”中按需下载词库；安装后离线查询，词典正文不打包进 APK，也不会自动下载或更新。
  • 将选中文字、笔记或书签制作成摘录卡片，并由您选择保存到系统图片库或分享给其他应用。
  • 在您主动使用时，通过 Bing、百度或 Google 等搜索服务查找网络封面；在您选择仿宋字体时按需下载远程字体。

2.2 应用性质

  • 本地阅读、本地解析和系统 TTS 默认不上传书籍内容。
  • WebDAV、MinerU 云端解析、第三方 TTS 和 AI 翻译均为可选网络功能，需您主动配置、启用或确认。
  • 本应用不提供 Lumi 账号注册、登录或开发者运营的云端书库。
  • 本地词典查询在设备上完成，不上传查询词、书籍正文或过滤命中记录。词典内容来自第三方项目，具体来源、许可和 LUMI 的转换/过滤说明见应用内许可页面。
  • Lumi 原创代码以 GNU GPLv3 许可证发布，第三方组件及改编代码遵循各自许可证。

3.1 未成年人保护与合理使用

未满 18 周岁的用户应在监护人指导下选择阅读内容、合理安排阅读时间并适时休息，可使用系统屏幕时间管理及现有听书定时停止功能。听书定时停止仅是辅助工具，不等同于完整的未成年人防沉迷系统。

使用 WebDAV、云端解析、第三方 TTS、AI 翻译等联网服务应遵守服务方年龄要求，并在监护人指导下了解数据传输和费用；处理不满 14 周岁未成年人的个人信息，应依法取得监护人同意。

如涉及购买或赞助，应与用户的民事行为能力相适应；依法需要监护人同意或追认的，应取得相应同意或追认。未成年人付款及退款争议依法处理，不作未成年人付款一律不退的约定。

监护人的指导和监护责任不免除开发者依法应承担的未成年人保护责任。权益投诉和个人信息请求请发送至 huangder0104@126.com；请勿在公开 GitHub Issues 上传儿童个人信息。

本应用重视隐私保护。阅读数据默认保存在本机；网络封面搜索、贡献者/头像展示、远程字体下载、词典包下载、更新检查，以及您主动配置或启用的 WebDAV 同步、MinerU 云端解析、第三方 TTS、AI 翻译或外部链接访问会产生相应网络请求。已安装词典的查询和摘录卡片生成在本机完成；只有当您主动分享卡片时，图片才会交给所选接收应用。具体请见隐私政策。

七、第三方服务与用户自选服务

  • MinerU/OpenDataLab：用于云端 PDF 解析。首次启用前，您需要阅读并同意 OpenDataLab 的服务协议和个人信息保护政策，并确认文件上传。
  • WebDAV：由您填写服务器信息并决定手动或自动同步。同步数据可能包括电子书文件、书籍清单、阅读进度、书签、笔记和选中文本。
  • 第三方 TTS：由您选择服务、填写 Base URL/API Key 并确认风险。朗读文本段和风格提示会发送到相应服务。
  • AI 翻译：由您选择服务、填写 Base URL/API Key 并启用或手动触发。当前选中文本、目标语言和模型参数会发送到相应服务；开启 HTTP 时可能发生明文传输。
  • GitHub 及其 CDN：用于更新、贡献者列表、头像和远程字体下载；其网络日志和数据处理遵循 GitHub 及 CDN 自身政策。
  • 封面搜索服务：仅在您主动使用网络封面搜索时接收书名或搜索关键词，具体处理遵循 Bing、百度或 Google 等服务的政策。
  • 赞助/贡献者页面：打开页面时会请求 GitHub contributors API 并加载头像，GitHub 及其 CDN 会接收正常网络请求元数据。
  • 词典下载：只有您在设置中确认下载或更新时，应用才会从配置的 GitHub Release 下载词库包；安装后的查询不调用在线词典服务。
