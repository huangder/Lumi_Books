隐私保护

本地优先，云端由你决定

阅读数据默认留在设备；只有主动配置或启用 WebDAV、MinerU、第三方 TTS 等网络功能时，相关书籍、阅读数据或朗读文本才会发送到对应服务。

🛡️

本地优先 · 主动授权 · 零追踪

Lumi 不使用第三方分析、广告、用户画像或崩溃上报 SDK。书架、阅读进度、笔记和书签默认存储在设备本地沙盒中。可选的 WebDAV 同步、MinerU 云端解析和第三方 TTS 默认不替你启用，使用前会由你配置、确认或同意风险提示。

🌐

联网场景透明

除更新、公告和政策版本检查外，WebDAV 同步、MinerU 解析、第三方 TTS 与外部链接均由你主动配置、启用或点击。

📵

无追踪 SDK

无 Firebase、无分析、无广告、无开发者运营的账号云书库；WebDAV、MinerU 和第三方 TTS 是可选或用户自选服务。

🔐

密钥本机加密

MinerU Token、WebDAV 密码和第三方 TTS API Key 使用 Android Keystore 加密保存，并排除系统备份/设备迁移。

本地存储什么？

应用会在本机保存书架、阅读进度、书签、笔记、选中文本、阅读时长、阅读偏好、文件/文件夹授权 URI，以及您配置的 WebDAV、MinerU、第三方 TTS 设置。第三方 TTS 返回的音频片段可能缓存在应用缓存目录中，以减少重复请求。

什么时候会上传或发送内容？

  • WebDAV 同步：向你配置的服务器上传/下载书籍文件、书籍清单、阅读进度、书签、笔记和选中文本。
  • MinerU 云端解析：把你选定的 PDF、解析参数和任务标识发送给 OpenDataLab/MinerU；精准解析还会使用你的个人 Token。
  • 第三方 TTS：把当前朗读文本段、模型/音色、风格提示和必要鉴权信息发送给你选择的 OpenAI、Xiaomi MiMo 或兼容服务。
  • 外部链接：只有在你主动点击 GitHub、反馈、下载或第三方协议链接时才会访问对应网站。

权限申请

可能申请的权限：

  • READ_EXTERNAL_STORAGE（Android 12 及以下）— 读取你选择的电子书文件
  • WRITE_EXTERNAL_STORAGE（Android 9 及以下）— 兼容旧系统保存文件或写回授权 TXT
  • READ_MEDIA_IMAGES（Android 13 及以上）— 读取封面或图片资源
  • INTERNET / ACCESS_NETWORK_STATE — 更新检查、WebDAV、MinerU、第三方 TTS 和外部链接
  • WRITE_SETTINGS — 启用自定义亮屏时间时修改屏幕关闭时间
  • FOREGROUND_SERVICE / POST_NOTIFICATIONS — TTS 播放、解析和同步进度通知

不申请的权限：

  • ✕ 位置信息权限
  • ✕ 相机/麦克风权限
  • ✕ 通讯录权限
  • ✕ 电话状态权限
  • ✕ 短信、日历等与阅读无关的敏感权限

开源透明

作为开源项目，Lumi 的完整源代码公开可审查。你可以查阅 Room 数据库、DataStore、WebDAV、MinerU、TTS 和 WebView 网络限制等实现，验证以上隐私承诺。
