技术，退后一步。
让文字走到前面。

从页面如何绘制，到数据如何留在本地，Lumi 的实现围绕一个目标：让阅读顺畅，让选择清楚。

01 / DRAW

文字如何成为一页

基础阅读器使用 Android 原生排版与 Canvas 渲染文本页，翻页时复用页面表面，避免依赖 WebView 承担主要文字排版。PDF 按页渲染，并通过有限页缓存控制内存使用。EPUB 原书排版则保留网页内容结构与链接。

02 / UNDERSTAND

书籍如何被打开

阅读管线覆盖 EPUB、PDF、TXT、MOBI、无 DRM 的 AZW / AZW3、CBZ 与 Markdown。解析、排版、页面定位与阅读进度交由不同模块处理；Markdown 提供目录、搜索、代码高亮、表格和公式等原生阅读能力。

03 / REMEMBER

阅读如何留下痕迹

书架、进度、书签、笔记、高亮和阅读偏好保存在本地数据层。Room 管理结构化阅读数据，DataStore 保存轻量设置，书籍文件继续由用户授权的本地位置管理。应用不要求 Lumi 账号。

04 / CONNECT

连接由你决定

WebDAV、云端 PDF 解析、第三方朗读或 AI 翻译等功能按需配置和触发。凭据在设备上加密保存。公开版和官方版共享基础数据结构，以保持数据库、备份与同步数据兼容。

05 / REVIEW

代码可以被审查

Lumi 的公开源码包含基础阅读、数据模型与公共功能接缝。官方 Premium 使用独立私有实现仓库，基础数据格式保持兼容；阅读报告、标签管理、高级摘录与授权实现属于官方版本。
